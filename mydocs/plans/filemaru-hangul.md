# 파일마루 전용 한글 포크

사용자 지시(2026-10-31): RHWP 전체 웹 기능을 파일마루용 포크로 만든다.

## 기준과 범위
Studio 소스는 upstream v0.8.7 (1a76570e833917d15817415a53c09ad61ab3203f)에서 동기화한다. Rust 코어는 동일 버전의 공식 @rhwp/core 배포본을 고정한다. 이 포크의 기존 Rust 소스 전체를 0.8.7로 표시하지 않는다. 기존 설치 매니페스트와 이력을 보존한다.
전체 웹 편집 명령, 메뉴·서식·표·도형·이미지·수식·쪽·찾기·인쇄·지원 내보내기를 유지한다. Windows 전용 HwpCtrl/브라우저 확장 설치는 웹 기능이 아니므로 별도 설치하지 않는다.

## 파일마루 전용 변경
- 자체 호스팅 빌드 및 파일마루 제목. 외부 폰트/CDN·PWA 서비스워커는 사용하지 않는다.
- 파일 열기/단축키는 부모의 내부 탐색창에 위임. HWP/HWPX 및 엔진 지원 HML을 보존한다.
- 저장/다른 이름 저장은 부모의 생성 전용 업로드 경로. HWP/HWPX 형식 선택을 유지한다. HTML/DOC/PDF 내보내기는 원본 명령을 보존한다.
- 정확한 부모 창/origin을 확인하는 전용 브리지. 열기 실패/크기 제한/세션 해제는 호스트에서 처리한다.
- 모든 문서 변경 revision을 추적한다. 저장 완료와 동일 revision에서만 clean 표시한다.
- 최근 문서/자동복구/문서 비교 이력은 인증된 호스트가 제공하는 계정 ID로 IndexedDB 이름을 구분한다. 기존 브라우저 복구 기능을 유지하되 서버 백업으로 표시하지 않는다.

## 검증·배포
npm 타입 검사/파일마루 lint, 실제 PC·360px 열기/편집/내보내기/재열기/취소. 포크 한국어 커밋/푸시 후 고정 자산을 호스트에 포함하고 호스트 커밋/푸시/재배포/HTTP 및 핵심 화면 확인.
